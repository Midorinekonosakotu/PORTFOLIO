# --- Pinball ---
### 制作時間
1週間

### こだわり
プランジャーを溜める時、離す時に、上下の動きを本物っぽくした

### 操作方法
下矢印キー長押しでプランジャーを溜める
左右矢印キーでフリップ操作
上矢印キーでボール位置リセット


# --- PaperSumo ---
### 制作時間
約4日

### こだわり
土俵のすべての角から衝撃を加えられるようにした

### 操作方法
A、Zキーで左の力士、F、Cキーで右の力士に衝撃を与える

# --- PlayingCatch ---
[4]:https://midorinekonosakotu.github.io/PORTFOLIO/PlayingCatch/

### 制作時間
約1日

### こだわり
ボールの速度を少し早くして、テンポ良く操作できるようにした

### 操作方法
A、LキーでPlayer1、2がボールキャッチ
S、KキーでPlayer1、2がボールを相手に投げる
